# 本地 2FA 验证码工具

读取 `input/secrets.txt`，在控制台输出当前六位 TOTP 验证码和剩余有效时间。固定使用 SHA-1、30 秒时间窗口，适用于采用这些参数的验证器账户。工具完全离线运行，无需代理；不进行账户登录或 OAuth 授权。

## 使用

需要 Python 3.8 或更新版本。核心逻辑和测试仅使用标准库，`requirements.txt` 已声明无第三方依赖，无需安装包。

首次使用，在本工具目录复制输入模板：

```bat
copy input\secrets.example.txt input\secrets.txt
```

将 `input/secrets.txt` 中的公开测试密钥替换为自己的密钥，然后双击 `run.bat`。默认输入路径始终相对于本工具目录，不受启动位置影响。

输入文件使用 UTF-8 编码，支持 BOM。每行填写一个 Base32 密钥，也可以使用 `邮箱----密码----2FA密钥` 格式；第一项须为邮箱，密码字段会被忽略。空行和 `#` 开头的行会跳过，密钥中的空白和大小写会自动规范化。错误行只报告行号及原因，其余有效行继续处理。

也可以把输入文件拖到 `run.bat`，或指定文件：

```bat
run.bat "D:\private\secrets.txt"
python main.py "D:\private\secrets.txt"
```

控制台只输出行号或账户邮箱、验证码和剩余有效时间，不输出密钥或密码，不生成日志及结果文件。真实输入已由本目录 `.gitignore` 排除；示例文件中的密钥是公开测试数据。请保持系统时间准确；临近窗口结束时，应在下一窗口重新运行工具获取验证码。

BAT 会检查 Python 并保留窗口供查看结果。退出码 `0` 表示全部成功，`1` 表示存在无效输入行，`2` 表示文件读取失败或输入为空，`3` 表示 BAT 未找到符合版本要求的 Python。

## 结构与验证

`main.py` 中的 `TotpGenerator` 负责密钥校验和标准算法，`TotpConsole` 负责输入格式、错误隔离及控制台输出。BAT 只负责启动和传递退出码。

在本工具目录运行：

```bat
python -m unittest discover -s tests -v
```

测试使用 RFC 6238 的公开 SHA-1 向量验证六位验证码，并覆盖时间边界、前导零、输入格式、错误隔离及凭据不回显。
